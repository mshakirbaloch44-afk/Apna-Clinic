Apna Clinic — GitHub Pages web/PWA build
1. Create or open GitHub repository apna-clinic.
2. Upload the FILES from this ZIP directly to the repository root (index.html, manifest.webmanifest, sw.js, icon.svg). Do not upload the ZIP itself.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Site URL: https://YOUR-USERNAME.github.io/apna-clinic/
5. Add to Home Screen on Android/iPhone (browser support varies).
6. Data is stored only in each browser localStorage, not synchronized. Do NOT enter real patient records until a secure backend, login, permissions, audit trail and backups are implemented.
7. Dashboard colors and layout were not intentionally changed; branding only.
8. Existing localStorage key intentionally retained to preserve data when updating the same origin.
